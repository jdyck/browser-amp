# Retired Clean Tube models

Clean Tube and Clean Tube Warm preceded the current six-model design. They were original two-stage waveshaper voicings, not hardware replicas.

Saved selections migrate as follows:

- Clean Tube → Blackface Combo
- Clean Tube Warm → Small Tweed Combo

Current behavior is defined by the [amp model specification](jazz-amp-models-spec.md).
